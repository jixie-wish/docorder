# Code of conduct

[中文](CODE_OF_CONDUCT.md)

In discussions, issues, and code review for this project, comment on the work. Personal attacks, harassment, and hostile content that is unrelated to the topic are not accepted.

If an interaction is unacceptable, open an issue whose title starts with `[conduct]`, or contact the maintainer privately. The maintainer may delete comments, lock a discussion, or reject the related contribution.
